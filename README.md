# Portfólio de Ana Luiza Vidigal

Site pessoal com meus projetos, experiências e formação.

## Projetos em destaque

- **Alento:** landing page conceitual de um spa urbano, do naming ao front-end. [Ver o site](https://analuvidi.github.io/AlentoLP/).
- **Bestiário Antigo:** site em PHP sobre saurópsidos fósseis do Brasil, navegado por um cladograma interativo.
- **App de leitura:** design de interface de um app para acompanhar leituras, feito no Figma.

## Tecnologias

- [Astro](https://astro.build/) para as páginas
- [React](https://react.dev/) nos componentes interativos
- [Tailwind CSS](https://tailwindcss.com/) no visual
- [GSAP](https://gsap.com/) e [Motion](https://motion.dev/) nas animações
